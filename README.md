NYC Yellow Taxi 2024 Analysis
Conducted comprehensive analysis of 39 million NYC Yellow Taxi trips from 2024, processing 5.5GB of data using Python and Pandas. Implemented memory-efficient batch processing techniques to handle large-scale datasets on standard hardware.
Key Findings:
Identified peak demand hours and seasonal patterns for operational optimization
Analyzed revenue trends across 12 months totaling $1,123,958,804.13
Discovered payment preference patterns and tip behavior insights
Provided data-driven recommendations for pricing and resource allocation
Technical Approach:
Data cleaning: Handled 4M+ missing values and removed 88K+ erroneous records
Feature engineering: Created temporal and derived metrics for analysis
Visualization: Generated 10+ charts showing trends, patterns, and distributions
Tools: Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
